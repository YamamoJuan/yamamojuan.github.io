## Portfolio website using [Nextjs](https://nextjs.org).
You can fork and use this as you want.

### What inside?
- Auto deploy using github workflows

### What used?
- Nextjs
- Fontawesome (Icons)
- Plus Jakarta Sans (Font)

### Dev testing
Simply run:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
